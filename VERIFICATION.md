# Computation record

**Date:** 3 October 2026.

The code cells of all four notebooks were read from their source, concatenated in notebook order and executed in separate Python processes. Every process completed with exit code 0. Each process started with a fresh namespace, and the Matplotlib `Agg` backend rendered the figures without a graphical desktop.

This validates sequential execution of the Python code and generation of figures and CSV outputs. Jupyter kernel execution and interactive notebook rendering were not part of this check.

## Numerical outputs

- In notebook 01, the naive difference in means is approximately **3.4271**, compared with the true ATE of **2**; adjusted regression gives approximately **1.9741**.
- In notebook 02, Horvitz–Thompson IPW gives approximately **1.9943** and Hájek IPW approximately **1.9924**.
- Notebook 03 reports limited overlap, weight truncation and trimming. Trimming at propensity scores 0.05 and 0.95 retains **2,768 of 5,000** observations in the recorded sample.
- Notebook 04 produces **2,700 estimator records**: three estimators across 300 replications and three scenarios. Its aggregated results are in `results/04_monte_carlo_summary.csv`.

The saved CSV files and displayed figures were generated by this verification run. Last-decimal differences may occur with other numerical-library versions.
